# MINI-INTERPRETER

A simple mini interpreter written in C++ using string parsing.

## Features

- Variable declaration
- Arithmetic operations
- Print statements
- Expression evaluation
- String-based parsing

## Example Program

```txt
let x = 10
let y = 20
let z = x + y

print x
print y
print z
print z * 5
```

## Output

```txt
10
20
30
150
```

## Concepts Used

- String Parsing
- Interpreters
- Expression Evaluation
- Hash Maps
- C++ Streams

## Technologies

- C++
- STL
- stringstream
- unordered_map

## Compile

```bash
g++ main.cpp -o interpreter
./interpreter
```
